1. # Architecture
2. 
3. ## System Overview
4. 
5. Deck Controller is structured as a DeckyLoader plugin with two layers:
6. 
7. - **Frontend** — React/TSX UI rendered inside Steam's Quick Access Menu
8. - **Backend** — Python 3.10+ service that reads controller input, encodes HID reports, and transmits over Bluetooth
9. 
10. Communication: frontend ↔ backend via DeckyLoader's RPC mechanism (`@decky/api` `callable()`).
11. 
12. ```
13. ┌─────────────────────────────────────────────────────────┐
14. │  Frontend (React/TSX)                                   │
15. │  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌───────────┐  │
16. │  │ MainView │ │DeviceList│ │ Settings │ │useBackend │  │
17. │  └────┬─────┘ └────┬─────┘ └────┬─────┘ └─────┬─────┘  │
18. │       └─────────────┴────────────┴─────────────┘        │
19. │                         │ callable() RPC                │
20. ├─────────────────────────┼───────────────────────────────┤
21. │  Backend (Python)       ▼                               │
22. │  ┌──────────┐ ┌──────────┐ ┌─────────────┐ ┌────────┐  │
23. │  │ main.py  │→│  Config  │ │ InputReader │ │pack_   │  │
24. │  │ Plugin   │ │          │ │  (evdev)    │ │report()│  │
25. │  └────┬─────┘ └──────────┘ └──────┬──────┘ └───┬────┘  │
26. │       │                           │             │       │

59. ## Data Flow
60. 
61. ```
62. Steam Deck Controller
63.     │ (physical input)
64.     ▼
65. evdev (/dev/input/eventN)
66.     │ EV_KEY / EV_ABS
67.     ▼
68. InputReader
69.     │ apply deadzone, update InputState
70.     │ callback(InputState)
71.     ▼
72. Plugin (main.py)
73.     │ pack_report(buttons, axes, triggers, dpad)
74.     ▼
75. pack_report() → 14-byte HID report
76.     │
77.     ▼
78. BTHIDService.send_report()
79.     │ 0xA1 + report
80.     ▼
81. L2CAP PSM 19 → Target Device
82. ```
83. 
84. ### Report Structure (14 bytes)
85. 
86. | Offset | Size | Field | Range |
87. |--------|------|-------|-------|
88. | 0 | 1 byte | Report ID | `0x01` |
89. | 1 | 2 bytes | Buttons | 16-bit bitmask (LE) |
90. | 3 | 2 bytes | Left Stick X | −32768 to 32767 |
91. | 5 | 2 bytes | Left Stick Y | −32768 to 32767 |
92. | 7 | 2 bytes | Right Stick X | −32768 to 32767 |
93. | 9 | 2 bytes | Right Stick Y | −32768 to 32767 |
94. | 11 | 1 byte | L2 Trigger | 0–255 |
95. | 12 | 1 byte | R2 Trigger | 0–255 |
96. | 13 | 1 byte | D-pad (lower nibble) | 0–7 dir, `0x0F` neutral |
97. 
98. ## State Machine
99. 
100. ```
101.         ┌─────────────────────────────────────────────┐
102.         │                                             │
103.   [Plugin loaded]                             stop_broadcasting()
104.         │                                             │
105.         ▼                                             │
106.      ┌──────┐  start_broadcasting()  ┌──────────────┐ │
107.      │ Idle │ ────────────────────→  │ Broadcasting │ ┘
108.      └──────┘                        └──────┬───────┘
109.         ▲                                   │
110.         │ stop_broadcasting()    L2CAP accept│
111.         │                                   ▼
112.         │                           ┌───────────┐
113.         └────────────────────────── │ Connected  │
114.               Device disconnects    └───────────┘
115. ```
116. 
117. | State | `_running` | `_connected_device` | Behavior |
118. |-------|-----------|---------------------|----------|
119. | Idle | `False` | `None` | Normal Steam Deck; default bluetoothd |
120. | Broadcasting | `True` | `None` | bluetoothd restarted with `-P input`; discoverable; L2CAP listening; evdev grabbed |
121. | Connected | `True` | `ConnectionInfo` | HID reports sent on input change; discoverable |
122. 
123. ## Technology Stack
124. 
125. | Layer | Technology | Why |
126. |-------|-----------|-----|

1. # SteamOS Constraints
2. 
3. ## Read-Only Root Filesystem
4. 
5. SteamOS 3.x uses immutable A/B root partitions:
6. 
7. - `/` is read-only (btrfs snapshot)
8. - System updates replace the entire root partition
9. - Modifications are lost on update
10. - `steamos-readonly disable` breaks the update mechanism
11. 
12. **Impact**: no system packages, no persistent config file edits, all plugin files in user-writable paths.
13. 
14. ## Writable Paths
15. 
16. | Path | Purpose | Survives Updates |
17. |------|---------|-----------------|
18. | `~/homebrew/` | DeckyLoader root | ✅ |
19. | `~/homebrew/plugins/<name>/` | Plugin code and assets | ✅ |
20. | `~/homebrew/settings/<name>/` | Plugin configuration | ✅ |
21. | `/tmp/` | Temporary files | ❌ (reboot clears) |
22. | `~/.local/` | User-local data | ✅ |
23. 
24. Deck Controller uses:
25. - **Code**: `~/homebrew/plugins/deck-controller/`
26. - **Config**: `~/homebrew/settings/deck-controller/config.json`
27. - **Logs**: via `decky.logger`
28. 
29. ## bluetoothd Management
30. 
31. BlueZ's `bluetoothd` input plugin conflicts with HID device emulation.
32. 
33. ### Activation Sequence
34. 
35. ```bash
36. systemctl stop bluetooth                    # 1. Stop default bluetoothd
37. /usr/lib/bluetooth/bluetoothd \
38.   -P input --nodetach                       # 2. Restart without input plugin
39. hciconfig hci0 class 0x002508              # 3. Set device class to Gamepad
40. bluetoothctl discoverable on                # 4. Enable discovery
41. bluetoothctl pairable on                    # 5. Enable pairing
42. bluetoothctl agent NoInputNoOutput          # 6. PIN-less agent
43. ```
44. 
45. ### Deactivation Sequence
46. 
47. ```bash
48. pkill -f "bluetoothd.*-P input"            # Kill custom bluetoothd
49. systemctl start bluetooth                   # Restore systemd service
50. ```
51. 
52. ### Why Not Edit `/etc/bluetooth/main.conf`?
53. 
54. - Read-only filesystem — changes lost on update
55. - `-P input` flag achieves the same effect at runtime
56. - Plugin handles it transparently
57.

59.

61. |--------|------|---------|
62. | `_main()` | Plugin loaded | Initialize services |
63. | `_unload()` | Plugin disabled / Steam shutdown | Restore bluetoothd, close sockets |
64. | `_uninstall()` | Plugin removed | Full cleanup |

67. - `plugin.json` with `"flags": ["root"]` for privileged operations
